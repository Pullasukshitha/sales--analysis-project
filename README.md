#  SQL Data Analysis Project (Sales & Customer Insights)

##  Overview
This project analyzes sales and customer data using SQL to generate meaningful business insights. It focuses on data aggregation, filtering, grouping, and joining multiple tables to understand sales performance and customer behavior.

##  Tools Used
- SQL (MySQL / SQL Server)
- Excel / CSV (for dataset preparation)

## Dataset Description
### 1. Sales Table
Contains transaction-level sales data:
- order_id
- date
- region
- city
- category
- product
- sales
- cost
- profit

### 2. Customers Table
Contains customer information:
- order_id
- customer_name
- customer_type
- gender
- age
- join_date

##  Data Relationship
Both tables are connected using:
- order_id

- ##  SQL Concepts Used
- SELECT queries
- WHERE filtering
- ORDER BY sorting
- GROUP BY aggregation
- HAVING clause
- Aggregate functions (SUM, AVG, MIN, MAX)
- CASE WHEN statements
- Joins (INNER JOIN, LEFT JOIN, RIGHT JOIN,)

---

##  Key Business Insights
- Identified top-performing products based on sales
- Analyzed region-wise sales performance
- Calculated total profit and average sales
- Segmented customers based on attributes
- Filtered high-performing regions using conditions
- Created category-based profit analysis

### Project Outcome
This project demonstrates practical SQL skills used in real-world data analysis, reporting, and business decision-making. It shows how raw data can be transformed into meaningful insights using SQL.
